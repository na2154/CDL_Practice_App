# CDL Study Hub

A study website for the Virginia Class A CDL knowledge tests. Notes for 9 units that can be read aloud, flashcards with a hands-free Listen mode, quizzes, practice tests, and a 6-week plan with 30 minutes a day of checkboxes.

## Files
- `index.html` — the page
- `styles.css` — the look
- `app.js` — read-aloud, flashcards, quizzes, plan
- `content.js` — all the study notes, flashcards, quiz questions, and the plan. **Edit this file to change content.**

## Put it online with GitHub Pages
1. On github.com, click **New repository**. Name it `cdl-study`, set it to **Public**, and create it.
2. Click **uploading an existing file**, drag in all four files above, and click **Commit changes**.
3. Go to **Settings → Pages**. Under "Build and deployment", set Source to **Deploy from a branch**, Branch to **main** and folder **/ (root)**, then **Save**.
4. Wait about a minute. The site will be at `https://na2154.github.io/CDL_Practice_App/#/`.

On a phone, open the link and use "Add to Home Screen" so it opens like an app.

Progress (checkmarks and quiz scores) is saved in the browser on each device.
